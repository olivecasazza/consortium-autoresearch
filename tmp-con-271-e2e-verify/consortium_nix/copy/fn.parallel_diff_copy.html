pub fn parallel_diff_copy(
    targets: &[&CascadeCopyTarget],
) -> Vec<(String, String)>
Expand description

Run a nix copy per target in parallel, returning per-host failures. Used by the cascade’s per-host diff phase: after the shared substrate has been distributed via the fan-out tree, each host that needs a different actual toplevel runs its own nix copy from seed. nix’s content-addressed store ensures only the missing tail is transferred, so these copies are tiny.
