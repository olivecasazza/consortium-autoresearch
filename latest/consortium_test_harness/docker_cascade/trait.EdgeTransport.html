Expand description

The per-edge action a DockerCascadeExecutor delegates to.

Split out from the executor so the failure/partition decision logic — the part that must stay identical to the sim tier — is testable without Docker, and so a future transport (e.g. one that pushes from src rather than streaming through the host) is a drop-in.

Source

fn transfer( &self, src: NodeId, tgt: NodeId, timeout: Duration, ) -> Result<Duration, CascadeError>

Move the payload src holds to tgt within timeout, returning the wall-time of the real hop. Errors must be transient-shaped ([CascadeError::Copy]) so the coordinator retries the target from an alternate source rather than declaring it dead.

fn seed(&self, _node: NodeId) -> Result<(), CascadeError>

Stage the payload on a node before the cascade starts. Defaults to a no-op for transports that need no staging step.
