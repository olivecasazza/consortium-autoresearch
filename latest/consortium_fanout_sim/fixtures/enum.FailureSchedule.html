Expand description

Injects deterministic failures into the cascade. The DeterministicExecutor calls failure_for(round, src, tgt) for every edge it dispatches; non-None returns become the edge’s outcome.

Variants§

§

None

No failures.

§

KillNodeAtRound

Fail every edge whose target is node, starting at round.

Fields

§node: NodeId
§round: u32
§

PartitionAtRound

Fail the specific (src, tgt) edge at round.

Fields

§src: NodeId
§tgt: NodeId
§round: u32
§

Random

Fail each edge with probability fraction (0.0 to 1.0). The outcome is deterministic — same seed, round, src, tgt produce the same fail/succeed decision via a hash of all four, so reproducing a “weird” failure pattern is just a matter of re-running with the same seed.

Fields

§fraction: f64
§seed: u64
§

Explicit(HashMap<(u32, NodeId, NodeId), CascadeError>)

Fail edges per a hand-built table: (round, src, tgt) -> Error.

§

All(Vec<FailureSchedule>)

Multiple failure schedules composed (any one matching = fail).

§

PeerSshUnconfigured

Models a fleet where peer-to-peer SSH isn’t configured but seed → peer SSH works (the nixlab default: dev box has SSH to every host, but cluster hosts don’t trust each other’s keys). Every edge whose src != seed returns a transient CascadeError::Copy mimicking real Permission denied / Host key verification failed stderr — the cascade should re-route those targets to seed-source on the next round.
