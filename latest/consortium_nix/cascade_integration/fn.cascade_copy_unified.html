Run a single cascade that distributes a multi-path payload (e.g. the closure intersection of every host’s toplevel) to every host in targets via the fan-out tree.

Differs from cascade_copy_grouped: there’s no group-by-toplevel step — every target is in ONE cascade, and the payload is passed explicitly. Use this for closure-intersection cascades where the payload is computed upstream from many heterogeneous toplevels.

The per-target toplevel_path field is ignored for routing — only host_name and ssh_addr matter here. (We keep the type for API parallelism with the grouped variant.)
